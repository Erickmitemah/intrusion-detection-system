Algorithm Type Use Case in IDS Strengths Limitations Complexity

ISOLATION FOREST Anomaly Detection Detect zero-day / unknown attacks as anomalies No labels needed, handles high-dimensional data High false positive rate, threshold tuning needed O(n log n)
